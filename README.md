BERETS / АСТРА

Адаптивный тренажёр по школьной астрономии с 27 базовыми заданиями, шестью дополнительными созвездиями и отдельной викториной по α-звёздам. После построения пользователь отмечает альфа-звезду либо вершины астеризма, а в викторине отвечает на вопросы с пятью вариантами.

При первом открытии сайт предлагает короткое интерактивное руководство. В нём на примерах Геркулеса и Южного Креста показано, как ставить точки, переключать готовые вершины, повторным нажатием снимать выбор и начинать отдельную линию. Руководство остаётся доступно из верхнего меню.

Как устроена проверка

Пользователь ставит точки нажатием на поле либо через форму X/Y. Последняя точка становится активной; чтобы начать новую ветвь, достаточно нажать любую уже поставленную вершину. Следующим нажатием можно соединить её и с новой, и с уже существующей точкой. Кнопка разрыва линии не нужна. Повторное соединение тех же двух точек учитывается один раз. Кнопка «Готово — проверить» запускает сверку в любой момент, поэтому знать количество точек заранее не требуется.

Все задания схематические: перенос, поворот, отражение, порядок постановки точек и общий масштаб свободны. Базовый порог зачёта — 70%, его можно изменить в настройках. Один отрезок всегда считается совпавшим по форме, а для пересекающихся отрезков дополнительно учитывается место пересечения. После построения пользователь находит ключевые звёзды и выбирает их названия из пяти вариантов.

Общие эталоны собраны из схем, сохранённых автором тренажёра, и защищены от изменения посетителями. Каждый пользователь может менять личные копии эталонов и добавлять собственные созвездия с названием и α-звездой — они хранятся только в его браузере. По умолчанию в верхнем меню остаются тренировка созвездий и викторина; настройка «Контрольные на оценку» добавляет отдельные контрольные для обоих форматов. Для каждого режима отдельно включается расширенный набор. В настройках также доступны светлая, тёмная и системная темы.

Все фигуры перерисованы по зелёным соединительным линиям на картах [Wikipedia / Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:English-language_constellation_maps). Для Ориона, Пегаса, Лебедя, Дракона и Большого Пса используются узнаваемые учебные контуры из соответствующих карт. Адаптация карт Torsten Bronger / Kxx распространяется на условиях CC BY-SA 3.0.

В разделе «Эталоны» можно выбрать любой объект, перерисовать его, переключаться между готовыми вершинами, отметить новую α-звезду и сохранить вариант. Встроенный набор неизменяем: каждый посетитель сохраняет собственную копию только в своём браузере и не может перезаписать схемы автора или других пользователей. Для каждого объекта доступен возврат к исходной схеме Wikipedia.

Состав летне-осеннего и зимнего треугольников сверен с материалом [NASA об астеризмах](https://science.nasa.gov/solar-system/skywatching/what-are-asterisms/). Альфа-звезда означает звезду с обозначением α по Байеру и не во всех созвездиях буквально является самой яркой.

Локальный запуск

Откройте `index.html` напрямую или запустите любой статический сервер в корне проекта. Команда `npm run build` собирает готовую для публикации копию в `dist`.
