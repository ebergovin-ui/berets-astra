# АСТРА

Адаптивный тренажёр по школьной астрономии. Он выдаёт одно из 25 созвездий или один из двух звёздных треугольников, предлагает воспроизвести схему на координатной плоскости и затем отметить альфа-звезду либо вершины астеризма.

## Как устроена проверка

Пользователь ставит точки с шагом 0,5 и соединяет их последовательными нажатиями. Проверка не привязана к месту рисунка: перенос, поворот, отражение и общий масштаб разрешены. Сравниваются количество точек и отрезков, степени вершин, относительные длины, углы и попарные расстояния.

Девять схем перенесены непосредственно из файла учительницы `таблица созвездия ЗАДАНИЕ.docx`: Лебедь, Лира, Андромеда, Дракон, Цефей, Персей, Кассиопея, Малая Медведица и Большая Медведица. Для остальных использованы нормализованные линии созвездий из проекта [d3-celestial](https://github.com/ofrohn/d3-celestial) под лицензией MIT.

Состав летне-осеннего и зимнего треугольников сверен с материалом [NASA об астеризмах](https://science.nasa.gov/solar-system/skywatching/what-are-asterisms/). Альфа-звезда означает звезду с обозначением α по Байеру и не во всех созвездиях буквально является самой яркой.

## Локальный запуск

Откройте `index.html` напрямую или запустите любой статический сервер в корне проекта. Команда `npm run build` собирает готовую для публикации копию в `dist`.
