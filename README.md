# BERETS / АСТРА

Адаптивный тренажёр по школьной астрономии с одной случайной лентой из 36 заданий: все 25 созвездий и два звёздных треугольника в схематическом виде, а также девять отдельных точных заданий по координатам. После построения пользователь отмечает альфа-звезду либо вершины астеризма.

## Как устроена проверка

Пользователь ставит точки нажатием на поле либо через форму X/Y. Последняя точка становится активной; чтобы начать новую ветвь, достаточно нажать любую уже поставленную вершину. Следующим нажатием можно соединить её и с новой, и с уже существующей точкой. Кнопка разрыва линии не нужна. Повторное соединение тех же двух точек учитывается один раз. Кнопка «Готово — проверить» запускает сверку в любой момент, поэтому знать количество точек заранее не требуется.

Задания перемешиваются в одной ленте, но проверяются по-разному. Девять дополнительных схем из файла учительницы — точные координатные задания: должны совпасть положение, целые координаты, масштаб и связи. Все 27 основных заданий — схематические: перенос, поворот, отражение, порядок постановки точек и общий масштаб свободны, а зачёт начинается с 85% сходства. Проверка сначала сопоставляет структуру графа, затем математически совмещает рисунки с разрешёнными преобразованиями. Процент показывается после каждого нажатия «Готово» и в итоговом окне.

Девять схем перенесены непосредственно из файла учительницы `таблица созвездия ЗАДАНИЕ.docx`: Лебедь, Лира, Андромеда, Дракон, Цефей, Персей, Кассиопея, Малая Медведица и Большая Медведица. Все остальные фигуры перерисованы только по зелёным соединительным линиям на картах [Wikipedia / Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:English-language_constellation_maps). Использованы компактные учебные фигуры: например, у Ориона семь основных звёзд, у Тельца — V-образная голова Гиад и два рога. Адаптация карт Torsten Bronger / Kxx распространяется на условиях CC BY-SA 3.0.

Состав летне-осеннего и зимнего треугольников сверен с материалом [NASA об астеризмах](https://science.nasa.gov/solar-system/skywatching/what-are-asterisms/). Альфа-звезда означает звезду с обозначением α по Байеру и не во всех созвездиях буквально является самой яркой.

## Локальный запуск

Откройте `index.html` напрямую или запустите любой статический сервер в корне проекта. Команда `npm run build` собирает готовую для публикации копию в `dist`.

Публичная версия без зависимости от ChatGPT: [ebergovin-ui.github.io/berets-astra](https://ebergovin-ui.github.io/berets-astra/).
