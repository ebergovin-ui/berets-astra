# BERETS / АСТРА

Адаптивный тренажёр по школьной астрономии. Он выдаёт одно из 25 созвездий или один из двух звёздных треугольников, предлагает воспроизвести схему на координатной плоскости и затем отметить альфа-звезду либо вершины астеризма.

## Как устроена проверка

Пользователь ставит точки только на целых координатах — нажатием на поле либо через форму X/Y — и соединяет их последовательными действиями. Когда набрано нужное количество точек и отрезков, проверка запускается автоматически. Она не привязана к месту рисунка: перенос, поворот, отражение и общий масштаб разрешены. Сравниваются количество точек и отрезков, степени вершин, относительные длины, углы и попарные расстояния.

Девять схем перенесены непосредственно из файла учительницы `таблица созвездия ЗАДАНИЕ.docx`: Лебедь, Лира, Андромеда, Дракон, Цефей, Персей, Кассиопея, Малая Медведица и Большая Медведица. Для остальных использованы линии западной звёздной культуры из открытого набора [Stellarium Sky Cultures](https://github.com/Stellarium/stellarium-skycultures/blob/master/western/index.json), перенесённые по реальным положениям звёзд на целочисленную сетку. У Ориона оставлена узнаваемая семизвёздная учебная схема, у остальных объектов отброшены только периферийные декоративные ответвления.

Состав летне-осеннего и зимнего треугольников сверен с материалом [NASA об астеризмах](https://science.nasa.gov/solar-system/skywatching/what-are-asterisms/). Альфа-звезда означает звезду с обозначением α по Байеру и не во всех созвездиях буквально является самой яркой.

## Локальный запуск

Откройте `index.html` напрямую или запустите любой статический сервер в корне проекта. Команда `npm run build` собирает готовую для публикации копию в `dist`.

Публичная версия без зависимости от ChatGPT: [ebergovin-ui.github.io/berets-astra](https://ebergovin-ui.github.io/berets-astra/).
