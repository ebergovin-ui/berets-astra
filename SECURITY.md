# Безопасность BERETS / АСТРА

Сайт намеренно остаётся статическим: у него нет сервера приложений, базы данных, аккаунтов учеников, формы входа, API и секретов в браузере. Координаты и статистика тренировки не отправляются в сеть; статистика хранится локально в браузере пользователя.

## Защитные меры

- Content Security Policy разрешает скрипты, стили, шрифты и изображения только с собственного адреса сайта; сетевые запросы, фреймы, плагины, медиа и web workers запрещены.
- Trusted Types запрещают создавать исполняемый HTML из строк в поддерживаемых браузерах.
- Динамический текст выводится через `textContent` и DOM-узлы, без `innerHTML`, `eval` и внешнего JavaScript.
- Ручной ввод координат принимается только как целое число в диапазоне сетки.
- Referrer Policy не передаёт адрес страницы сторонним сайтам.
- Исходный репозиторий не содержит ключей и токенов; временные ключи публикации не сохраняются в Git.

## Управление

Публичность сайта даёт посетителям только просмотр. Изменять исходник или выпускать новые версии могут лишь владельцы/редакторы проекта на хостинге. Перед каждой публикацией нужно проверять список редакторов и не добавлять посторонних.

## Честная граница

Абсолютно «невзламываемых» сайтов не существует. Безопасность также зависит от защиты аккаунта владельца и инфраструктуры хостинга. Для владельца обязательны уникальный пароль, многофакторная аутентификация и запрет передачи сессионных ссылок или временных Git-токенов.
